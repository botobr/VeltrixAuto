# Veltrix – frontend

React 19 + Vite. A telepítés, a beállítások és a tesztek leírása a projekt fő README-jében van: [../README.md](../README.md).

```bash
npm install
npm run dev      # http://localhost:5173 (a backend a http://localhost:3600-on fusson)
npm run lint
npm run build
npm run e2e      # Cypress E2E tesztek (saját tesztszerverrel, az éles adatokhoz nem nyúl)
```
